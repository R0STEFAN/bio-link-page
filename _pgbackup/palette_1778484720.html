Усі основні кольори, напівпрозорі шари й градієнти, які формують атмосферу сторінки.

Tokens

Основні кольори

Background

--bg

#080707
  • Базовий фон HTML і тіла сторінки.
  • Підкладка під прозорі шари й фото.

Ink

--ink

#f4eee7
  • Основний текст: ім'я, заголовки, назви кнопок.
  • Світлі лінії та напівпрозорі контури через rgba.

Muted

--muted

#a99f98
  • Другорядний текст у палітрі та службові підписи.
  • Тихий контраст там, де не потрібен акцент.

Copper

--copper

#d69b66
  • Eyebrow-текст, іконки, focus outline.
  • Акценти кнопок, hover-стани й теплі підсвітки.

Moss

--moss

#7b8b74
  • Радіальне світіння на фоні сторінки.
  • Другий тон у градієнтах головної та акцентної кнопок.

Deep Brown

background stop

#16100f
  • Середня точка фонового градієнта.
  • Тепла глибина замість плоского чорного.

Layers

Прозорі шари

Line

--line

rgba(244, 238, 231, 0.14)
  • Рамки кнопок, свотчів, секцій і прикладів.
  • Тонкі розділювачі без жорсткого білого контуру.

Surface

--surface

rgba(18, 15, 14, 0.72)
  • Основний фон звичайних кнопок.
  • Панелі прикладів із blur-ефектом.

Surface Strong

--surface-strong

rgba(29, 23, 21, 0.9)
  • Головна кнопка запису.
  • Hover-стани, де поверхня має стати щільнішою.

Copper Soft

--copper-soft

rgba(214, 155, 102, 0.2)
  • М'яке світіння та декоративна тепла підкладка.
  • Підходить для нових бейджів або виділених блоків.

Shadow

--shadow

rgba(0, 0, 0, 0.48)
  • Велика тінь під фото-панеллю на десктопі.
  • Глибина темних елементів без світлого контуру.

Hover Border

button hover

rgba(214, 155, 102, 0.68)
  • Колір рамки кнопки при наведенні.
  • Показує інтерактивність без зміни композиції.

Градієнти

Фон сторінки

  • Використовується на body у bio page та palette page.

Головна кнопка

тепла мідь із тихим зеленим відтінком

  • Використовується в .link-item.primary для запису.

Акцентна кнопка

moss першим шаром, copper як підсвітка

Фото-панель

вертикальна тінь поверх портрета

  • Використовується у .photo-panel поверх портретного фото.
linear-gradient(180deg, transparent, rgba(8,7,7,.52))

Мобільний оверлей

темний нижній шар для компактної версії

  • Використовується в mobile .bio-page::after.
linear-gradient(180deg, rgba(8,7,7,.2), rgba(8,7,7,.96))
